## Математичний вираз варіанта 11

У ЛР1–5 використовується вираз:

```text
                 2,33 · ln(√(1 + cos²(y)))
I(x, y) =        ─────────────────────────
                       eʸ + sin²(x)
```

Для ЛР1–3 значення `x` вводиться користувачем, а `y = 1.0` ініціалізується у програмі.

## Лабораторна робота №1

### Завдання

Обчислити значення математичного виразу. Один аргумент отримати від користувача, інший ініціалізувати конкретним значенням.

### Реалізація

На сторінці ЛР1 користувач вводить `x`. Програма задає `y = 1.0` і безпосередньо обчислює вираз методами класу `Math`:

- `Math.cos` і `Math.sin` — тригонометричні функції;
- `Math.pow` — піднесення до степеня;
- `Math.sqrt` — квадратний корінь;
- `Math.log` — натуральний логарифм;
- `Math.exp` — експонента.

Результат відображається в текстовій області GUI.

## Лабораторна робота №2

### Завдання

Додати перевірку області допустимих значень виразу.

### Реалізація

Перед обчисленням перевіряється:

1. `x` і `y` є скінченними числами;
2. підкореневий вираз `1 + cos²(y)` не від'ємний;
3. аргумент логарифма додатний;
4. знаменник `eʸ + sin²(x)` не дорівнює нулю;
5. знаменник є скінченним числом.

На сторінці GUI показуються проміжні числові значення кожної умови.

## Лабораторна робота №3

### Завдання

Обробити некоректне введення одного з аргументів як виняткову ситуацію.

### Реалізація

Перетворення тексту на число й обчислення виконуються всередині `try`. Обробляються:

- `NumberFormatException` — введений текст не є числом;
- `IllegalArgumentException` — значення не належать ОДЗ.

Помилка показується на сторінці ЛР3, а графічний застосунок продовжує працювати.

## Лабораторна робота №4

### Завдання

Обчислити вираз для всіх значень `x` із заданого проміжку двома циклами: `for` і `while`.

Для `N = 11`:

```text
x ∈ [-10 - 2,5N; 5 + 1,2N] = [-37,50; 18,20]
Δx = 0,5 + N/20 = 1,05
```

### Реалізація

Сторінка ЛР4 дозволяє обрати цикл `for`, `while` або обидва. Результати формуються у вигляді таблиці.

Значення `x` визначається через номер ітерації:

```java
double x = START_X + i * STEP;
```

Це зменшує накопичення похибки типу `double`. На кожній ітерації виконується перевірка ОДЗ.

## Лабораторна робота №5

### Завдання

Перенести аргументи виразу в окремий клас, додати конструктори, методи `get/set`, статичний і нестатичний способи обчислення.

### Реалізація

GUI повторно використовує клас `lab5.expression.ExpressionCalculator`.

Демонструються:

- конструктор без параметрів;
- конструктор із параметрами;
- приватні поля `x` та `y`;
- гетери й сетери;
- нестатичний метод `calculate()`;
- статичний метод `ExpressionCalculator.calculate(x, y)`.

Обидва способи повертають однаковий результат для однакових аргументів.

## Лабораторна робота №6

### Завдання

Спроєктувати щонайменше три класи, пов'язані успадкуванням та агрегацією або композицією. Продемонструвати конструктори, перевантажені й перевизначені методи.

### Реалізація

Використано класи:

- `Ingredient` — інгредієнт;
- `Dish` — страва;
- `HotDish` — гаряча страва.

`Dish` агрегує список `Ingredient`. `HotDish` успадковує `Dish`.

У GUI створюються овочевий салат та український борщ. Використовуються обидві перевантажені версії `addIngredient`. Виклик `showInfo()` через посилання типу `Dish`, яке містить об'єкт `HotDish`, демонструє поліморфізм і перевизначення методу.

Початкові класи ЛР6 виводять дані в консоль. Клас `ConsoleCapture` без зміни цих класів перенаправляє їхній вивід у текстове поле GUI.

## Лабораторна робота №7

### Завдання

Доповнити ієрархію ЛР6 абстрактним класом або інтерфейсом та продемонструвати реалізацію абстрактних методів.

### Реалізація

Використано:

- `Cookable` — інтерфейс із методами `cook()` і `getCookingInstructions()`;
- `AbstractCookedDish` — абстрактний клас;
- `Soup` — конкретний клас супу;
- `BakedDish` — конкретний клас запеченої страви.

`AbstractCookedDish` успадковує `HotDish` та реалізує `Cookable`. `Soup` і `BakedDish` по-різному реалізують методи приготування.

Об'єкти зберігаються через посилання абстрактного типу, а метод `cook()` викликається через змінну типу `Cookable`. Це демонструє поліморфізм.

## Архітектура графічного застосунку

Точка входу — `project1.Project1Application`.

`MainFrame` містить:

- бічне меню;
- `CardLayout` для перемикання сторінок;
- сторінки ЛР1–7;
- головну сторінку;
- сторінку автора.

Спільне оформлення зберігається в `AppStyle`, а математична логіка ЛР1–4 — в `ExpressionService`.

Таке розділення не змішує інтерфейс, обчислення та предметні класи.

## Інструкція користувача

### Запуск

1. Відкрити папку репозиторію у VS Code.
2. Перейти до панелі **Run and Debug**.
3. Обрати **СР1 — Проєкт 1 (GUI)**.
4. Натиснути `F5`.

### Робота із застосунком

1. Обрати потрібну лабораторну в меню ліворуч.
2. Ввести дані у поля форми.
3. Натиснути кнопку обчислення або демонстрації.
4. Переглянути результат у нижній частині сторінки.
5. Для ЛР4 обрати потрібний тип циклу.
6. Для перегляду даних автора відкрити **Про автора**.

Дробову частину можна відокремлювати крапкою або комою.

## Перевірка працездатності

Проєкт компілюється в режимі сумісності з Java 8. Перевірено запуск головного GUI-вікна та компіляцію всіх залежностей із ЛР5–7.

У межах самостійної роботи створено єдиний графічний Java-застосунок для лабораторних робіт №1–7.
