# Фото автора

Додайте в цю папку власну фотографію з назвою `author.jpg`.

Якщо використовується інша назва або формат, змініть значення `photo` у файлі `project1/author.properties`.

Рекомендована вертикальна фотографія зі співвідношенням сторін приблизно 4:5. Застосунок автоматично масштабує зображення без спотворення пропорцій.
