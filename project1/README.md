# CP1. Проєкт 1

Графічний Java-застосунок, який об'єднує функціональність лабораторних робіт №1–7 для варіанта 11.

## Можливості

- окремі сторінки для ЛР1–7;
- введення даних безпосередньо у вікні програми;
- перевірка помилок і зрозумілі повідомлення;
- таблиця значень виразу для циклів `for` і `while`;
- демонстрація класів, конструкторів, інкапсуляції та статичних методів;
- демонстрація агрегації, успадкування й поліморфізму;
- демонстрація абстрактного класу та інтерфейсу;
- сторінка з інформацією про автора та фотографією.

Повний зведений опис робіт і кодових рішень міститься у файлі [REPORT.md](REPORT.md).

## Запуск у VS Code

1. Відкрийте у VS Code папку `C:\Forme\Other\Repo\java`.
2. Відкрийте панель **Run and Debug** за допомогою `Ctrl+Shift+D`.
3. У списку конфігурацій виберіть **СР1 — Проєкт 1 (GUI)**.
4. Натисніть `F5` або зелену кнопку запуску.

Також програму можна запустити посиланням **Run** над методом `main` у файлі `Project1Application.java`.

### Ручний запуск із PowerShell

Якщо `javac` і `java` доступні через `PATH`, виконайте з кореня репозиторію:

```powershell
$sources = Get-ChildItem project1, lab5, lab6, lab7 -Filter *.java -Recurse
javac --release 8 -encoding UTF-8 -d out $sources.FullName
java -Dfile.encoding=UTF-8 -cp out project1.Project1Application
```

## Користування програмою

1. Після запуску відкриється головне вікно.
2. Оберіть потрібну лабораторну роботу в меню ліворуч.
3. Введіть значення у відповідні поля.
4. Натисніть кнопку виконання.
5. Результат з'явиться в текстовій області нижче.
6. Для перегляду інформації про розробника відкрийте сторінку **Про автора**.

Дробові числа можна вводити через крапку або кому.

## Дані автора

Особисті дані зберігаються у файлі [author.properties](author.properties):

```properties
name=Прізвище Ім'я По батькові
group=Назва групи
university=Назва закладу освіти
discipline=Програмування Java
variant=11
photo=project1/assets/author.jpg
```

Фотографію потрібно додати як `project1/assets/author.jpg`. Можна використати інше ім'я або формат, якщо змінити значення `photo`.

## Структура

```text
project1/
├── Project1Application.java        точка входу
├── author.properties               дані автора
├── README.md                       інструкція користувача
├── REPORT.md                       зведений опис ЛР1–7
├── assets/
│   └── author.jpg                  фотографія автора
├── core/
│   ├── ExpressionService.java      математична логіка ЛР1–4
│   └── ConsoleCapture.java         перенесення console output у GUI
└── ui/
    ├── MainFrame.java              головне вікно і навігація
    ├── HomePanel.java              стартова сторінка
    ├── ExpressionLabPanel.java     сторінки ЛР1–3
    ├── Lab4Panel.java              сторінка ЛР4
    ├── Lab5Panel.java              сторінка ЛР5
    ├── Lab6Panel.java              сторінка ЛР6
    ├── Lab7Panel.java              сторінка ЛР7
    ├── AuthorPanel.java            інформація про автора
    └── AppStyle.java               оформлення інтерфейсу
```

Класи ЛР5–7 повторно використовуються з пакетів `lab5`, `lab6` та `lab7`. Логіка ЛР1–4 винесена в `ExpressionService`, оскільки початкові консольні класи розташовані в стандартному пакеті й не можуть імпортуватися у названий пакет Java.

## Вимоги

- JDK 8 або новіша версія;
- VS Code із розширенням **Extension Pack for Java** або інше Java IDE;
- додаткові бібліотеки не потрібні — GUI реалізовано стандартними засобами Swing.
